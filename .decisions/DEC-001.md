---
id: DEC-001
title: Billing never calls a model API
level: error
---

## Decision

Nothing under `examples/billing/` imports a model SDK.

## Why

Billing has to be deterministic and auditable: the same invoice must always
produce the same total and the same message, with no per-call cost and no data
leaving the service.

## Rules

```rule
forbid import openai, anthropic, langchain
in examples/billing/**
```

## Fix

Keep billing deterministic. If you need generated text, produce it outside
billing and pass it in as a plain string.
